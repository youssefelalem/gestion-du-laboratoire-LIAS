قاموس البيانات والمواصفات المرجعية (Dictionnaire de Données)

يُعد قاموس البيانات (Dictionnaire de Données) المرجع الهندسي الأسمى لتصميم قاعدة البيانات ونظام المعلومات. يحدد هذا المستند المواصفات الدقيقة لجميع الكيانات، الجداول (Tables)، الحقول (Colonnes)، الأنواع في SQL و Java EE، المفاتيح الأساسية والخارجية (PK / FK)، القيود الحتمية (NOT NULL, UNIQUE)، وقواعد التدبير المهنية (Règles de Gestion) المستنبطة نصاً من دفتر تحملات مختبر LIAS.

🔬 المنهجية الأكاديمية الصارمة المعتمدة (Méthodologie d'Ingénierie Logicielle — UP / 2TUP)

كيف تم بناء قاموس البيانات ومخطط الأصناف؟ (De la modélisation dynamique à la structure statique) :
لم نكتفِ مطلقاً بنسخ الجداول البسيطة الموجودة في الكود البرمجي الأولي، بل اتبعنا دورة الهندسة الأكاديمية المعيارية دقة بدقة (Méthode rigoureuse pas-à-pas) :

  1. تفريغ معطيات السيناريوهات (Dépouillement des Scénarios de Séquence) : من خلال رسائل ومخططات التسلسل (DSS و DSBB)، قمنا باستخراج كافة الحقول المتبادلة في الاستمارات (مثل استمارة الانخراط: nom, prenom, email, statutVise, إلخ).
  2. التجميع الدلالي والترتيب حسب الانتماء (Regroupement par Entité Métier) : تم تجميع الحقول المترابطة وظيفياً لتتحول كل مجموعة متجانسة إلى صنف (Classe) في مخطط الأصناف وجدول (Table) في قاموس البيانات.
  3. الإكمال الشامل من دفتر التحملات (Complétion exhaustive depuis le CDC LIAS) : الحقول الزمنية العميقة التي لا تظهر في الاستمارات المباشرة (مثل فترات الانتساب affiliation_periods، عهود الإدارة mandats، محاضر الاجتماعات reunions_pv، والاتفاقيات conventions) تم استنباطها حرفياً من نصوص دفتر التحملات (§2، §3، §6، §8، §12-17).
💡 المبادئ الهندسية الأساسية المطبقة في قاموس بيانات مختبر LIAS :
1. الفصل الصارم بين العضوية والحساب (Découplage Compte / Profil) : جدول users مخصص للأمان وحفظ التجزئة، بينما جدول members مخصص للمعلومات الأكاديمية والإنتاج العلمي.
2. مبدأ عدم المسح والتأريخ التراكمي (Historisation Temporelle Non-Destructive) : عند انتهاء انتساب عضو أو تقاعده، لا يُحذف سجله نهائياً بل يتم تجميد حسابه وتسجيل تاريخ انتهاء الفترة (date_fin).
3. تعقيم وتأمين المدخلات (Sécurisation JDBC) : كل حقل في القاموس يمتلك حداً أقصى للطول (Taille Maximale) وقيداً للنزاهة لمنع فيض البيانات والحقن البرمجي.

1. حسابات المستخدمين والمصادقة الأمنية (Authentification & Sécurité)

أمان وتحكم بالصلاحيات (RBAC)

تخزن هذه الفئة بيانات الولوج للمنصة. يطبق النظام آلية التحكم بالصلاحيات القائمة على الأدوار (Role-Based Access Control). الحسابات تديرها إدارة النظام، وترتبط بالملفات الأكاديمية ارتباطاً اختيارياً (0..1) لتمكين المشرفين غير الباحثين من الولوج.

اسم الحقل (Champ) البيان والتوصيف (Libellé) نوع SQL نوع Java EE القيود (Contraintes) قواعد التدبير والملاحظات (Règles de Gestion CDC)
id المعرف الرقمي الفريد للمستخدم BIGINT Long PK AUTO_INC تزايد تلقائي تسلسلي. مفتاح أساسي مطلق.
nom اللقب العائلي للمستخدم VARCHAR(100) String NOT NULL إجباري. يحتوي فقط على حروف ومسافات.
prenom الاسم الشخصي للمستخدم VARCHAR(100) String NOT NULL إجباري. يُستخدم في الترحيب والترويسة.
email البريد الإلكتروني المهني (معرف الدخول) VARCHAR(150) String UNIQUE NOT NULL مفتاح طبيعي للولوج (Login). فريد تماماً، نسق RFC 5322.
password كلمة المرور المشفرة VARCHAR(255) String NOT NULL مخزنة كـ Hash آمن (BCrypt/SHA-256). لا تُخزن نصاً صريحاً.
role الدور الوظيفي في النظام VARCHAR(50) String NOT NULL قيم معيارية: directeur, permanent, doctorant, admin, visiteur.
actif حالة تفعيل الحساب BOOLEAN boolean DEFAULT TRUE يُضبط على FALSE لتجميد حساب المتقاعدين أو المستقيلين.

2. الملفات الأكاديمية للباحثين (Membres & Profils Académiques)

الملفات الأكاديمية والعضوية

تمثل هذه الفئة المركزية سجل الباحث العلمي داخل المختبر، متضمنة وضعه الأكاديمي، فريقه البحثي، ودرجته العلمية. تفصل بين وضعه الأكاديمي الدائم (Statut) ومسؤوليته التسييرية الراهنة (Rôle).

اسم الحقل (Champ) البيان والتوصيف (Libellé) نوع SQL نوع Java EE القيود (Contraintes) قواعد التدبير والملاحظات (Règles de Gestion CDC)
id المعرف الأكاديمي الرمزي للعضو VARCHAR(50) String PK معرف فريد كودي (مثل: yea, sb, as).
firstName الاسم الشخصي للباحث VARCHAR(100) String NOT NULL يُعرض في واجهة التعريف والبطاقات الشخصية.
lastName اللقب العائلي للباحث VARCHAR(100) String NOT NULL يُعتمد في الفهرسة الأبجدية للباحثين.
email البريد الإلكتروني للاتصال العلمي VARCHAR(150) String NOT NULL مطابق لبريد حساب users.email في حال امتلاكه حساباً.
status الوضعية الأكاديمية (Statut d'appartenance) VARCHAR(50) String NOT NULL القيم: permanent, associe, doctorant, retraite, ancien.
role المسؤولية الحالية في الحوكمة (Rôle) VARCHAR(50) String NOT NULL القيم: directeur, vice-directeur, chef-equipe, membre, aucun.
team الفريق البحثي التابع له الباحث VARCHAR(50) String NULLABLE إحدى الفرق الأربع: IA, Big Data, NLP, Sécurité.
grade الدرجة واللقب الجامعي VARCHAR(100) String NULLABLE أمثلة: PES, Professeur Habilité, Maître de Conférences, Doctorant.

3. فترات الانتساب والتأريخ الزمني للمسار (Historique des Affiliations)

التأريخ الزمني (Historisation)

تُجسد جوهر متطلبات دفتر التحملات في حفظ الذاكرة الأكاديمية للمختبر. تسمح بتسجيل فترات انضمام وخروج العضو وعودته لاحقاً، وبناء الخط الزمني الكامل (Cycle de vie) دون محو أي معطيات سابقة.

اسم الحقل (Champ) البيان والتوصيف (Libellé) نوع SQL نوع Java EE القيود (Contraintes) قواعد التدبير والملاحظات (Règles de Gestion CDC)
id المعرف الفريد لفترة الانتساب BIGINT Long PK AUTO_INC مفتاح ترقيمي تسلسلي لكل فترة انتساب.
member_id معرف الباحث صاحب الفترة VARCHAR(50) String FK NOT NULL مفتاح خارجي يشير إلى members.id. علاقة تركيب (1 ⟵ *).
date_debut تاريخ بداية فترة الانتساب DATE LocalDate NOT NULL تاريخ رسمي لبداية العقد أو الانتساب للمختبر.
date_fin تاريخ نهاية فترة الانتساب DATE LocalDate NULLABLE إذا كانت القيمة NULL، فهذا يعني أن العضوية سارية حالياً.
role_historique الصفة أو المسؤولية خلال هذه الفترة VARCHAR(50) String NOT NULL تحفظ الدور الأكاديمي خلال الفترة لمنع فقدان السياق التاريخي.
mandats

4. عهود الحوكمة وإدارة المختبر (Mandats de Direction & Gouvernance)

حوكمة وإدارة مؤسساتية

توثق عهود الإدارة المتعاقبة على قيادة مختبر LIAS. تفصل المنصب الإداري (Directeur en mandat) عن الصفة الأكاديمية الدائمة، وتحدد المسؤول المخول بالتوقيع على طلبات الانخراط، شراء المعدات والاتفاقيات.

اسم الحقل (Champ) البيان والتوصيف (Libellé) نوع SQL نوع Java EE القيود (Contraintes) قواعد التدبير والملاحظات (Règles de Gestion CDC)
id المعرف الفريد للمأمورية الإدارية BIGINT Long PK AUTO_INC تزايد تلقائي للمأموريات والولايات.
titre عنوان المأمورية الانتخابية VARCHAR(150) String NOT NULL مثال: "ولاية الإدارة 2024-2028: التحول نحو الذكاء الاصطناعي".
directeur_id معرف العضو المكلف بالإدارة VARCHAR(50) String FK NOT NULL مفتاح خارجي يشير لـ members.id (يجب أن يكون عضواً دائماً).
date_debut تاريخ سريان الولاية DATE LocalDate NOT NULL بداية العهد الرسمي المعتمد من عمادة الكلية.
date_fin تاريخ انتهاء الولاية DATE LocalDate NULLABLE تكون فارغة أثناء سريان العهد وتُسجل عند انتخاب مدير جديد.
actif مؤشر المأمورية الحالية BOOLEAN boolean NOT NULL لا يمكن أن يكون هناك سوى مأمورية نشطة واحدة في ذات الوقت (actif=1).

5. الإنتاج العلمي والمنشورات البحثية (Publications Scientifiques)

إنتاج علمي وببليوغرافيا

مستودع الإنتاج الفكري للباحثين وطلبة الدكتوراه، يشمل المقالات المفهرسة في المجلات العالمية والمؤتمرات الدولية، مصنفة حسب السنة، الفريق البحثي، ونوع الوعاء النشر.

اسم الحقل (Champ) البيان والتوصيف (Libellé) نوع SQL نوع Java EE القيود (Contraintes) قواعد التدبير والملاحظات (Règles de Gestion CDC)

auteurs قائمة المؤلفين والمشاركين VARCHAR(255) String NOT NULL أسماء الباحثين وفق معايير الاقتباس الأكاديمي الدولية.
annee سنة النشر والظهور INT int NOT NULL تُعتمد في حساب مؤشرات تقرير الأداء وحصيلة المختبر السنوية.
revue اسم المجلة أو وقائع المؤتمر VARCHAR(150) String NOT NULL أمثلة: IEEE Transactions, ACM Surveys, Springer LNCS.
doi المعرف الرقمي للمنشور (Digital Object ID) VARCHAR(100) String NULLABLE معرف فريد للوصول المباشر للورقة عبر الإنترنت (الرابط الدائم).
equipe الفريق البحثي الحاضن للورقة VARCHAR(50) String NULLABLE ربط الورقة بإحدى فرق المختبر: IA, Big Data, NLP, Sécurité.
type صنف الوعاء العلمي (Type de publication) VARCHAR(50) String NOT NULL قيم معيارية: Article (مجلة محكمة), Conférence (مؤتمر دولي).

titre عنوان الفعالية أو موضوع الندوة VARCHAR(255) String NOT NULL عنوان جذاب يوضح محور اللقاء العلمي.
type نوع النشاط الأكاديمي VARCHAR(50) String NOT NULL أمثلة: Conférence, Workshop, Séminaire, Soutenance.
date تاريخ انعقاد الفعالية VARCHAR(50) String NOT NULL نسق ISO (YYYY-MM-DD). يُعتمد للفرز الزمني التلقائي.

description ملخص وأهداف التظاهرة TEXT String NULLABLE شرح مفصل للبرنامج العلمي والمحاضرين المدعوين.
organisateur المنسق أو الباحث المشرف VARCHAR(100) String NOT NULL اسم الأستاذ الباحث أو الفريق المنظم للتظاهرة.
statut الوضعية الزمنية للفعالية VARCHAR(50) String NOT NULL القيم: À venir (قادمة), Passé (منتهية), En cours.

انخراط وتسجيل الباحثين

prenom الاسم الشخصي للمترشح VARCHAR(100) String NOT NULL بيانات الهوية الشخصية للمترشح.
email البريد الإلكتروني للاتصال بالمترشح VARCHAR(150) String NOT NULL يُعتمد لإرسال قرار الإدارة وبيانات الولوج عند القبول.

etablissement المؤسسة أو الجامعة الأصلية VARCHAR(150) String NULLABLE الكلية أو المركز البحثي الذي ينتسب إليه الباحث خارجياً.

dateSignature تاريخ توقيع الاتفاقية DATE LocalDate NOT NULL تاريخ توقيع مدير المختبر ورئيس المؤسسة الشريكة.
dateEcheance تاريخ انتهاء سريان الشراكة DATE LocalDate NULLABLE أجل انتهاء الاتفاقية أو موعد تجديدها الدوري.
statut الوضعية القانونية للاتفاقية VARCHAR(50) String NOT NULL قيم معيارية: Active (سارية), En négociation, Échue (منتهية).
